## 初次见面

我是 Xiaosu，一位来自善美城市的不知名小鬼。

### 善美城市是哪里？

善美其实谐音汕尾，广东汕尾，是我的家乡。每次在家乡路边闲逛的时候，经常会看到政府经常把汕尾叫成“善美”城市，好像其实本来想叫成“汕美”的，被汕头占了去了。

但汕尾却和汕头不同：汕头是新一线城市，同时也是经济特区；反观汕尾，最近几年，才刚刚提拔成三线。

看过我 Typecho 博客版本的朋友可能知道，原本博客 Slogan 这个“善美城市”，我其实是想把它写成“三线城市”的。

我一直觉得，自己能走到今天，能架设博客，能写写代码，离不开这个“三线善美城市”的帮助的。

### 什么时候开始接触电脑的？

第一次玩电脑还是 2015 年，我有了自己的台式机。那台台式机是联想的办公主机，配置应该算的上是比较差的了，里面预装着 Windows XP 系统（当时 Win8 都快出来了），拿到新电脑的第一天，还注册了自己的第一个 QQ，现在 QQ 勋章那个显示我的账号创建日期的勋章，已经显示不出来具体哪天了。

后面我把电脑当成一个大型手机玩，是真的在玩手游，不知怎的，我已经会安装手机模拟器了。当时安装的模拟器是腾讯游戏助手，我就在上面一直下载游戏玩，玩的什么已经不清楚了，唯一记得在那电脑上玩的游戏，是《球球大作战》，但那也是那台电脑运行的最后一个游戏了。玩游戏的时候，电脑有时会直接卡死，声音也卡死的那种，我就会尝试直接拔掉电源，然后插上电源重启，这招在我看来总是很灵，每次电脑都卡的死死的，断电之后总是能恢复过来，直到有一天游戏“正常”的卡死，可再尝试那一招，却把电脑整没了。

```bash
系统启动失败，原因是找不到 `xxx.sys` 文件。
请使用“修复计算机”工具解决此问题
```

那时的我虽然能读懂这段文字，但读起来仍像是天书，记忆中，那台电脑恰好就没有“修复计算机”的工具，找了父母过来帮忙，却只有父母的一句：

> 都怪你，把电脑搞坏了，这下好了，电脑都没得玩了。

从此以后，我就对电脑开始有着莫名其妙的认识……

### 又是什么时候开始接触编程的呢？

当时接触编程的时候真的可以用一句话总结：**“无聊能使鬼推磨”**

懂得都懂，小学时期，电子设备都是被家长严格控制的，我能自由支配时间的电子设备，就只有我爷爷买给我的那台步步高 S1 pro 家教机，而且并没有破解过，于是只能在几乎没有游戏的系统应用商店中，找到一个比较好玩的应用试水。

> 《编程猫 Nemo》，什么玩意，可以自己做游戏？试试看！

对的，我的编程启发，是编程猫跟我度过的，当时这对我来说就是一方充满自由的净土。

我在上面随便乱写乱作，后面写了一个算不上是计算器的计算器，里面是一排排按钮，写着“加法”、“减法”……按下那些按钮，就只有对话框，要你输入加数、减数等，然后加法就是编程猫积木里的“() + ()”，把两个对话框返回的变量，拼到上面去，自娱自乐嘛就没做多什么所谓的输入合理化等乱七八糟的检查。

后面 Nemo 准备要做社区功能了，我一时冲动，把这个“计算器”当作活动作品提交上去了，结果 Nemo 官方真的收录了我的作品，但是是毫无相干的“坑爹游戏”板块……

上首页了流量就是高，社区开发不到一周，我的作品浏览量就破千了，我也非常的高兴，自己成为这个社区里所谓的“元老级人物”，评论区虽然有人在说计算器功能差、为什么是“坑爹游戏”之类的，但大部分是对我的好评。

我第一次得到了编程，或者是创造力工程，带给我的“延迟满足”，这也让我对编程开发充满了信心。
